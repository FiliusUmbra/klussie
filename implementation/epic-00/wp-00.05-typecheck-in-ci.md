## Rollback

Remove the `Type-check` step and restore the job name. Four lines plus a
comment. No data, no application code, no dependency. `git revert` is
sufficient and complete.

## Notes

**Placed before `Test`, deliberately.** Type errors are cheap to detect
and the suite is not — the local run takes over twenty seconds. A type
error should fail the run in seconds rather than after the tests have
finished. Lint stays first because it is cheaper still.

**No `continue-on-error`, no soft launch.** The point of the package is
that type errors *block*. A warning-only gate teaches people to ignore
it, which is worse than not having it.
